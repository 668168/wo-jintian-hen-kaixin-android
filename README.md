# 我今天很开心 Android App

使用 Kotlin + Jetpack Compose 开发的 Android 原生 MVP。

## 已实现

- 首页、开心广场、打卡、日历、我的五个主页面
- 工作、生活、家庭、其他分类与 100 字限制
- 默认公开发布，也可设为仅自己可见
- 本地公开动态、点赞和评论
- Android 文档选择器选择图片或视频
- Android 系统语音识别输入
- 每日正念格言、每日打卡、连续打卡和打卡日历
- 每日 ¥1 奖励演示逻辑（不代表真实余额或支付承诺）
- SharedPreferences 本地持久化

## 尚未接入

用户注册登录、云数据库、真实多人社区、媒体上传后端、服务端点赞评论、内容审核与真实支付。
